# `_archive/` — Quarantined Backend Test Scripts

Files in this directory are **legacy review scripts** that were generated by the
testing agent across multiple rounds and accumulated as duplicate "test all
30 endpoints" suites. They are quarantined here for the following reasons:

## Why they're archived (not deleted)

1. **Not pytest-collected.** Each script wraps its tests in a class with
   `def __init__(self):`, which pytest silently skips. So they were never
   contributing to actual CI coverage.
2. **Hard-coded preview URL.** They hit
   `https://mintu-finance.preview.emergentagent.com/api` directly, bypassing
   the dynamic test fixture that real pytest tests use.
3. **Heavy duplication.** Three "comprehensive" suites had ~85% endpoint
   overlap (3,300+ LOC of repeated test logic).
4. **Polluted SonarQube** counts (each was being counted as a test file
   even though it contributed 0 collected tests).

## Files moved here (Phase 3 cleanup, ~3,890 LOC quarantined)

| File                                     | LOC | Notes                              |
|------------------------------------------|-----|------------------------------------|
| `comprehensive_backend_test.py`          | 941 | Duplicate of mintu comprehensive   |
| `backend_comprehensive_test.py`          | 950 | Duplicate                          |
| `backend_e2e_comprehensive_test.py`      | 781 | Duplicate                          |
| `simple_backend_test.py`                 | 130 | Only 1 test fn                     |
| `focused_backend_test.py`                | 318 | Only 3 test fns                    |
| `reaudit_test.py`                        | 310 | 0 pytest-collected tests           |
| `phase4_premium_test.py`                 | 210 | 0 pytest-collected tests           |
| `round34_regression_test.py`             | 250 | Subsumed by `regression_test.py`   |

## What remains in `tests/`

`test_comprehensive_mintu.py` (626 LOC) is retained as the **canonical**
comprehensive review script — it has the proper `test_` prefix and the
newest endpoint surface.

## How to restore

If a future audit needs any of these, run:

```bash
mv backend/tests/_archive/<filename>.py backend/tests/
```

## Coverage impact

Zero. None of these were producing coverage signal.
